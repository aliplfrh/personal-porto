### ✨ Highlights

- 🌌 **Ambient canvas background** — drifting monochrome orbs + mouse-follow glow + film grain & vignette (zero dependencies, DPR-aware, respects `prefers-reduced-motion`)
- 🎭 **Animated page transitions** via Framer Motion `AnimatePresence`
- 🗺️ **Interactive world map**, live clock, artwork carousel on the hero
- ✏️ **Built-in CMS** — edit hero, about, timeline & tools from the `/admin` page (persisted via Netlify Blobs, no rebuild needed)
- 📱 Fully responsive · ⚡ Vite-fast builds · 🌙 dark-first monochrome design

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ & npm

### Installation

```bash
# 1. Clone the repo
git clone https://github.com/aliplfrh/personal-porto.git
cd personal-porto

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Open http://localhost:5173 🎉

### Other Scripts

| Command | Action |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Type-check + production build → `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |

## 📁 Project Structure

```
src/
├── components/          # Hero, Navbar, Footer, AmbientBackground, WorldMap, Reveal…
├── pages/               # Home (Hero), About, WorksIndex, WorkDetail, Admin
├── content/             # SiteContentContext — editable site copy (CMS-backed)
├── data/                # projects.ts — portfolio entries
├── App.tsx              # Router + layout + ambient background mount
└── index.css            # Monochrome design system (CSS variables)
netlify/
└── functions/           # CMS API (Netlify Blobs)
```
